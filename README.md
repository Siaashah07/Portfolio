## 🌐 How to Host Online for Free on GitHub Pages
1. Create a repository on your GitHub account (`Siyaashah07`) named `portfolio` (or `<username>.github.io`).
2. Push the files in this folder (`index.html`, `data.js`, `README.md`).
3. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
4. Your portfolio will be live at:
   `https://Siyaashah07.github.io/portfolio` (or `https://Siyaashah07.github.io`)!
